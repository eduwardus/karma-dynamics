# Changelog

All notable changes to this project will be documented in this file.

This project adheres to [Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and uses [Semantic Versioning](https://semver.org/).

---

## [1.1.0] – 2025-07-07

### Added
- New `experimental/` directory containing multiple `.py` scripts for exploratory testing, model variations, and conceptual experiments.
- Additional utilities for statistical analysis, bifurcation detection, and advanced visualization.

### Improved
- Refactored and cleaned the original codebase for improved readability, efficiency, and modularity.
- Expanded inline documentation and comments to clarify core components of the karmic dynamics model.

## [1.0.1] – 2025-06-18

### Added
- Initial stable release of the Karmic Dynamics Computational Framework.
- Published with a DOI on Zenodo.
